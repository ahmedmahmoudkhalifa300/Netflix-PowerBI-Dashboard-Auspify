## About This Repository

This repository contains my project submissions and learning outcomes from the **Auspify Technologies Internship Program**. It serves as a structured portfolio of practical work completed across Business Intelligence, ETL data transformation, relational data modeling, DAX engineering, and executive dashboard design.

The project in this repository is organized according to the internship submission format and is designed to demonstrate the complete workflow of solving real-world data problems: understanding a business or analytical objective, preparing data, building a solution, evaluating results, documenting decisions, and communicating findings clearly.

## About the Internship

The **Auspify Technologies** internship is a project-based learning experience focused on applying technical knowledge to practical Business Intelligence tasks. The program encourages interns to build portfolio-ready dashboards, document their work, publish their implementations on GitHub, and present completed work through a project demonstration.

The internship workflow includes:

- Reviewing the assigned task and feature checklist.
- Building the project using the required technology stack.
- Documenting the implementation and results.
- Publishing the completed work in the official GitHub repository.
- Creating a demonstration of the completed project.
- Sharing the project professionally and participating in evaluation.
