## About This Repository

This repository contains my end-to-end project implementation, analytical documentation, and learning outcomes from the **Auspify Technologies Power BI Internship Program**. It serves as a structured Business Intelligence portfolio demonstrating the complete lifecycle of transforming raw streaming catalog data into an executive-ready, multi-page decision-support system.

The project is engineered to reflect industry-standard BI workflows: understanding strategic business objectives, performing ETL and data cleansing in Power Query, designing a relational Star Schema data model, authoring dynamic DAX measures, applying a cohesive **Netflix Dark UI/UX** visual identity, and delivering actionable executive recommendations.

## About the Internship

The **Auspify Technologies Power BI Internship** is a 4-week practical learning program designed to bridge the gap between academic concepts and industry-grade Business Intelligence reporting. The program emphasizes hands-on dashboard architecture, data storytelling, and portfolio development.

The internship workflow includes:

- Reviewing the assigned 6-task roadmap and analytical deliverables.
- Importing, cleaning, and modeling real-world datasets using Power Query and Power BI Desktop.
- Developing interactive multi-page dashboards with advanced DAX calculations, Field Parameters, Drill-Down hierarchies, and Drill-Through views.
- Validating metric accuracy and optimizing UI/UX responsiveness.
- Publishing the source files, documentation, and dashboard previews on GitHub.
- Presenting the completed solution professionally across industry networks.
